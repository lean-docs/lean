# Lean v0.1.0-alpha.2

DOCX saves preserve explicit formatting resets and all eighteen standard underline values. Named paragraph styles retain supported inherited run formatting, including explicit off declarations. Cyclic parent references fail style resolution.

Native Markdown files retain their original source bytes while providing sanitized HTML previews. CommonMark and GFM syntax rendering are available separately for conversion.

## Install

```bash
go get github.com/lean-docs/lean@v0.1.0-alpha.2
```

## Compatibility

Existing Go boolean literals retain their behavior. A zero-valued boolean means inheritance; use the formatting setters to request an explicit off declaration. Individual overrides can be cleared to resume inheritance.

Applications must check the fidelity capabilities before saving explicit resets or additional underline styles. Unknown underline values and unsupported underline properties prevent a canonical save.

Complete character-style and paragraph-property inheritance remain outside these formatting guarantees.
