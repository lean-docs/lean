# Lean v0.1.0-alpha.3

Document editing is available as validated, atomic command batches through Go and the command line. Commands cover text, paragraph and named styles, numbering, basic table structure, page and section layout, header/footer variants, anchored bookmarks and drawing insertion, positioning and removal. Failed batches leave their input unchanged.

Canonical DOCX exports preserve explicit paragraph resets, black text overrides, supported numbering restarts, independent section headers and footers, columns, bookmark anchors and auxiliary image/link relationships. Pictures retain cropping, rotation and wrap polygons. Supported shapes retain their geometry, fill, outline and editable text-box blocks, including nested pictures. First-page and even-page header switches preserve unused variant content.

## Install

```bash
go get github.com/lean-docs/lean@v0.1.0-alpha.3
```

## Compatibility

Check the fidelity report and command catalogue before editing. Fields, tracked changes, character-style references, arbitrary table styles and merged table rows remain unsupported for canonical editing. Structural commands refuse merged-cell edits. Grouped drawings, charts, custom geometry and advanced drawing effects remain outside the supported drawing subset.

Measurements use points. Text command positions use UTF-16 units and count an inline break as one unit. Ranges cannot split a supplementary Unicode character.
