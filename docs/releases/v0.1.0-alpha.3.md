# Lean v0.1.0-alpha.3

Document editing is available as validated, atomic command batches through Go and the command line. Commands cover text, paragraph and named styles, numbering, basic table structure, page and section layout, header/footer variants and anchored bookmarks. Failed batches leave their input unchanged.

Canonical DOCX exports preserve explicit paragraph resets, black text overrides, supported numbering restarts, independent section headers and footers, columns, bookmark anchors and auxiliary image/link relationships.

## Install

```bash
go get github.com/lean-docs/lean@v0.1.0-alpha.3
```

## Compatibility

Check the fidelity report and command catalogue before editing. Fields, tracked changes, character-style references, arbitrary table styles and merged table rows remain unsupported for canonical editing. Structural commands refuse merged-cell edits.

Measurements use points. Text command positions use UTF-16 units and count an inline break as one unit. Ranges cannot split a supplementary Unicode character.
