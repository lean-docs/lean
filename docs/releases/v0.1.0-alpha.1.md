# Lean v0.1.0-alpha.1

Lean's first alpha provides a portable Go foundation for document applications.
It uses one typed document representation across supported input and output
formats, so applications do not need to make an editor their data model.

## Included

- Conservative DOCX editing with explicit fidelity reports
- DOCX text, layout, formatting, tables, links, numbering, styles, and images
- CommonMark and HTML import and export
- Typst export for PDF, PNG, and SVG rendering
- Fixtures sourced from LibreOffice and python-docx
- A small CLI for checking the installed Lean version

## Install

```bash
go get github.com/lean-docs/lean@v0.1.0-alpha.1
```

Prebuilt CLI archives and checksums are attached to the GitHub release.

## Alpha constraints

The public API and fidelity guarantees can change before v1.0. Documents with
unsupported features remain read only. Applications must check the fidelity
report before offering editing or saving.
